# 数字图像处理算法文档

## 项目概述
数字图像处理算法仿真系统是一个用于教学和研究的软件工具，包含图像处理的核心算法实现。

## 算法分类

### 1. 图像生成算法
- **棋盘格图像**：用于测试滤波和边缘检测算法
- **同心圆图像**：用于测试边缘检测和分割算法
- **渐变图像**：用于测试图像增强算法
- **随机形状**：用于测试分割算法
- **测试图案**：综合测试图像

### 2. 噪声模型
- **高斯噪声**：模拟传感器噪声
- **椒盐噪声**：模拟传输噪声
- **斑点噪声**：模拟乘性噪声
- **泊松噪声**：模拟光子噪声

### 3. 滤波算法
#### 线性滤波
- **均值滤波**：简单平均，去除高斯噪声
- **高斯滤波**：加权平均，保留边缘

#### 非线性滤波
- **中值滤波**：去除椒盐噪声，保留边缘
- **双边滤波**：结合空间和颜色信息

#### 高级滤波
- **小波去噪**：多尺度去噪
- **非局部均值**：基于相似性的去噪

### 4. 边缘检测算法
#### 一阶微分算子
- **Sobel算子**：计算梯度幅值和方向
- **Prewitt算子**：简单梯度计算
- **Roberts算子**：交叉差分
- **Scharr算子**：改进的Sobel算子

#### 二阶微分算子
- **Laplacian算子**：二阶微分，对噪声敏感

#### 最优边缘检测
- **Canny算子**：多步骤最优边缘检测

### 5. 图像增强算法
#### 灰度变换
- **直方图均衡化**：全局对比度增强
- **CLAHE**：自适应对比度增强
- **伽马校正**：非线性亮度调整
- **对数变换**：压缩动态范围

#### 空间滤波
- **图像锐化**：增强边缘和细节
- **Retinex增强**：模拟人眼视觉

### 6. 图像分割算法
#### 阈值分割
- **Otsu算法**：自动阈值选择
- **自适应阈值**：局部阈值
- **三角形算法**：直方图分析

#### 聚类分割
- **K-means聚类**：基于颜色和空间特征

#### 区域分割
- **区域生长**：基于种子点的区域扩展
- **分水岭算法**：基于梯度图像

#### 高级分割
- **Mean Shift**：基于密度估计

## 算法性能评估

### 评估指标
1. **PSNR (峰值信噪比)**
   - 公式: PSNR = 20·log₁₀(MAX/√MSE)
   - 用途: 评估滤波算法的去噪效果

2. **SSIM (结构相似性)**
   - 范围: 0-1，越接近1越好
   - 用途: 评估图像结构保持度

3. **处理时间**
   - 单位: 毫秒(ms)
   - 用途: 评估算法效率

4. **边缘保持度**
   - 范围: 0-1
   - 用途: 评估边缘检测算法的鲁棒性

### 实验设计
1. **噪声水平影响分析**
   - 测试不同噪声强度下的算法性能

2. **参数敏感性分析**
   - 分析算法参数对性能的影响

3. **算法对比实验**
   - 对比不同算法在相同条件下的表现

## 使用指南

### 基本流程
1. **图像输入**
   - 生成测试图像
   - 加载外部图像

2. **预处理**
   - 添加噪声（可选）
   - 图像归一化

3. **算法应用**
   - 选择处理算法
   - 调整参数
   - 执行处理

4. **结果分析**
   - 可视化结果
   - 计算评估指标
   - 保存结果

### 参数选择建议
#### 滤波算法
- **均值/高斯滤波**：核大小5×5
- **中值滤波**：核大小5×5（对椒盐噪声）
- **双边滤波**：d=9, σ_color=75, σ_space=75

#### 边缘检测
- **Canny算子**：低阈值=50，高阈值=150
- **Sobel算子**：核大小3×3

#### 图像增强
- **伽马校正**：γ=1.5（增强），γ=0.5（减弱）
- **CLAHE**：clip_limit=2.0, grid_size=(8,8)

#### 图像分割
- **K-means**：K=3（一般场景）
- **Otsu阈值**：自动阈值选择

## 常见问题解答

### Q1: 如何选择合适的滤波算法？
A: 根据噪声类型选择：
- 高斯噪声：高斯滤波或均值滤波
- 椒盐噪声：中值滤波
- 混合噪声：双边滤波或非局部均值

### Q2: Canny算子的阈值如何设置？
A: 建议设置：
- 低阈值：图像梯度幅值的10%-20%
- 高阈值：低阈值的2-3倍
- 可通过实验确定最佳值

### Q3: 如何评估分割算法的效果？
A: 使用以下指标：
- 区域数量
- 区域均匀性
- 边界平滑度
- 如有真实标注，使用IoU等指标

### Q4: 处理时间过长怎么办？
A: 可尝试：
- 降低图像分辨率
- 使用更高效的算法
- 优化参数设置
- 使用并行处理（如果支持）
